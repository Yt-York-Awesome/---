# 智能家居控制系统（2024 金砖国赛 · 集成电路设计与应用）

基于正点原子 **MiniSTM32F103**（STM32F103RCT6）开发板的智能家居控制系统，2024 一带一路暨金砖国家技能发展与技术创新大赛 · **集成电路设计与应用全国总决赛三等奖**项目。

- 开发环境：Keil MDK5 + STM32F1 HAL 库 + ESP8266（AT 指令）+ 阿里云 IoT
- 配套终端：Android App（SOS 求助 / 远程控制）
- 本说明基于源码实际整理

---

## 一、功能特性

### 1. 环境监测与显示
- DHT11 采集温湿度，ATK-MD0240（2.4 寸 SPI LCD）实时显示：室内温度、室内湿度、设定温度、湿度上限、湿度下限。

### 2. 自动调节（本地闭环）
- **温度控制**：温度 > 设定值 → 继电器 2 启动降温设备；温度 < 设定值 → 继电器 1 启动加温设备。
- **湿度控制**：湿度 > 上限 → 3010 风扇开启除湿；湿度 < 下限 → 加湿器开启。

### 3. 云端互联（阿里云 IoT / MQTT）
- ESP8266（esp-01）通过 MQTT 接入阿里云物联网平台（产品 `k1tecyxqV8l`，设备 `esp-01`）。
- 支持云端远程控制：LED 灯、风扇、加湿器、报警、就医、救火、开窗/关窗、自动控制开关、温度/湿度调节等（`led`、`text` 属性指令）。
- 火焰检测到异常时自动向云端上报"救火"指令。

### 4. 语音控制
- 串口语音识别模块（UART 中断接收），指令码 0xA1~0xBD 对应：
  - 温度加/减、湿度上限加/减
  - 风扇开/关、加湿器开/关、开灯/关灯
  - 报警开/关、就医开/关、救火开/关、开窗/关窗

### 5. 环境安全监测
- **火焰检测**（PC3）：检测到火焰 → 通过 MQTT 向云端上报"救火"。
- **雨滴检测**（PA2）：检测到下雨 → 舵机动作（关窗）。
- **人体红外**（PB5）：检测到人 → 点亮 LCD；无人后由 TIM3 计时约 60 秒自动熄屏（节能）。

### 6. 按键调节
- 4 个按键（外部中断）调节：设定温度、湿度上限、湿度下限。

### 7. 配套 Android App
- `SOS最终.apk`：手机端 SOS 求助与远程控制终端（与阿里云 IoT 联动）。

## 三、系统架构与数据流

```
┌─────────────┐    ┌──────────────┐    ┌─────────────────┐
│  DHT11 温湿度 │    │  语音识别模块   │    │  按键（设定调节）   │
└──────┬──────┘    └──────┬───────┘    └────────┬────────┘
       │                  │                     │
       ▼                  ▼                     ▼
┌─────────────────────────────────────────────────────┐
│              STM32F103（主控，主循环 total()）          │
│  温湿度显示 · 温度/湿度自动调节 · 火焰/雨滴/红外监测     │
└──────┬──────────────────────┬──────────────────────┘
       │                      │
       ▼                      ▼
┌─────────────┐      ┌────────────────────┐
│ LCD 状态显示  │      │ ESP8266 → 阿里云 IoT │
│ 继电器/风扇/  │      │  (MQTT 远程控制/上报) │
│ 加湿器/舵机/灯│      └─────────┬──────────┘
└─────────────┘                ▼
                       ┌────────────────┐
                       │ Android App（SOS）│
                       └────────────────┘
```

主循环流程（`total()`）：
1. `ESP8266_MQTT_RECV` —— 接收云端下发控制指令
2. `Voice` —— 语音指令解析与执行
3. `Raindrop_control` —— 雨滴检测 → 关窗
4. `PageTemperatureHumidityProcess` —— 温湿度采集与显示
5. `JIDIANQIKZHI` —— 温度闭环（继电器加温/降温）
6. `PageinfraredProcess` —— 人体红外 → 亮屏 + 熄屏计时
7. `Humidity_regulation` —— 湿度闭环（风扇/加湿器）
8. `Flame_control` —— 火焰检测 → 云端"救火"上报

## 五、开发环境与构建

- **IDE**：Keil MDK5（μVision5）
- **芯片**：STM32F103RCT6（MiniSTM32F103 V4 开发板），72 MHz
- **库**：STM32F1 HAL 库 + 正点原子 MiniSTM32 例程基底
- **构建**：打开 `Projects/MDK-ARM/atk_f103.uvprojx` 编译，产物输出到 `Output/`

## 六、注意事项

1. **云平台凭据硬编码**：阿里云产品 ProductKey（`k1tecyxqV8l`）、设备名、MQTT 主题及 WiFi 账号密码均为源码硬编码，发布公开仓库前请注意脱敏或换用自己的实例。
2. **备用驱动**：BSP 内含 GY30（光照）与 SGP30（空气质量）驱动，当前主逻辑未调用（预留）。
3. **demo.c 为例程残留**：3D 立方体旋转演示代码未参与主流程。
